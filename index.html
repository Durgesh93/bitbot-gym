Bit:Bot Gym

Write the blocks in MakeCode, copy what its JavaScript tab shows, paste it here, and watch the robot do it. Nobody has to wait for the real one.

Program

Starting MakeCode… It opens with the 4tronix Bit:Bot extension already added, so both sets of drawers are there. This part needs the internet.

Build the blocks, press Transfer code to put them on the chosen board, then swipe to the room and press Play on that board's card. Each one runs on its own, so several can run at once. Open a .hex loads a program you have already built.

Program log

Shadow Monster learns how bright the room is when you press Run, then sleeps. Press Run, wait for the sleepy eyes, then switch the torch on — that is the jump it is waiting for. Drag the torch to chase it into the corners - it runs away from light, it does not follow it.

A simulation, not a promise. Battery level, wheel slip, the floor and the classroom lights all move the real numbers — the real Bit:Bot still gets the final word.
